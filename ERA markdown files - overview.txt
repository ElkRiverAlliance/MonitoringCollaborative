What do the different .Rmd files do?


Data Overview Markdown.Rmd -----------------------------------------------------

* starts with Consolidated_Data ("Consolidated Data-Selected.csv")
* updates this with DataFixes ("Consolidated_Data_Corrections_only.csv"). These include things like 'likely unit error'
* plots out pre- and post- correction figures for select variables
* plots out frequency of error types
* Stadia Maps. sets up:
  - map background
  - owner colours
  - Plot: sites by owner plot
  - Table Total Number of Sites 
  - Table: Sites w >12/Year Sample Frequency
  - Table: summary for several parameters
  - compares number of sites in fording vs wigwam
* Data Summary Graphs
  - input Parameter
  - For that parameter, creates the DataSummaryGraph - saved as paste(Parameter,"DataSummary.png")
    - DataOwnerSummary & donut plot
    - YearFreqPlot
    - SiteMap (size=number of years, shape=sampled>2015)
    - DataErrorPlot
    - DataSampleFrequencyPlot
* Top Years
  - input parameter
  - for each will 
    - list the site parameter is observed at
    - list and plot out the top 20 sites by unique(year) count
* Flow Seasonal & Temporal Graphs
  - select flow sites
  - makes FlowSummaryGraph, including:
    - FlowSiteMap
    - FlowTimeseriesPlot
    - FlowSeasonalityPlot
* For nitrogen, makes a summary plot, which includes
  - NitrogenDissolvedSiteMap 
  - NitrogenDissolvedDataDonut
  - NitrogenDissolvedYearFreqPlot
  - NitrogenDissolvedTimeseriesPlot
  - NitrogenDissolvedSeasonalityPlot
  - saves as NitrogenDissolvedDataSummary.png
* For selenium, several selenium parameter categories have been grouped together
  - Selenium Total
  - Selenate
  - Selenite
  - Selenocyanate
  - Selenomethionine
  - Selenosulfate

Data_Fixing_AM.Rmd -------------------------------------------------------------
* by AlexMcClymont
* read_csv("./Consolidated Data-selected.csv")
* checks / corrections
  - site names, location duplicates
  - result/value corrections (below detection, unit errors) - selenium, nitrogen, nickel, sulphur, sulfate, temperature, phosphorus, flow, selenate, selenite, turbidity, calcium
  - writes corrections only to "Consolidated_Data_Corrections_only.csv"
  - writes updated to "Consolidated_Data_Including_Corrections.csv"
  - Tables errors by error type, parameter, and data owner
